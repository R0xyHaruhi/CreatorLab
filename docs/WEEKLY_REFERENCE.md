# 每周必看100期精选参照

## 打开入口

切到B站空间，打开「看作品」，点击顶部战力图旁的「每周必看」。可以先浏览和筛选真实样本，导入B站作品后可选择一条进行对比。使用内置精选库无需登录B站。

## 本包数据

- 第292—391期，共100期当前可见清单，4,620条清单记录。
- 4,600条有效、去重作品，4,539条有公开标签。
- 20条排除记录：8条页面提示视频不存在，2条跳回首页，10条跳转节目/合集且不能确认单条视频播放量。保留BV号、期数和排除原因。
- 指标观测时间为2026-11-03的UTC时间。这些是采集时累计计数，不能还原入选那一周的固定窗口值。
- 本批播放、点赞的4,511条计数来自公开文档整数，89条来自“万”等页面缩写并保留近似标记。其他指标分别保留精度及缺失情况。

这是官方精选作品参照，不是全站随机样本或全站平均数据；当前可见清单也不保证等于最初上榜清单。没有混入后续未完成批次。

## 如何对比

默认使用这100期全部有效作品，不按作品年龄强制分组。可输入公开标签，选择任一或全部命中；可选择入选期数，也可主动开启发布时间范围。开启发布时间筛选时，时间未知的记录不进入所选范围。

标签匹配基于大小写和全半角规范化后的公开标签，按加权标签重合度排列候选。界面同时显示命中及未命中的查询标签。只命中COSPLAY不等于确认同一角色赛道；相似度不是置信概率或质量分。

可在“进一步细分”中选择必须同时命中的公开标签。候选及作品数来自上方标签、期数、时间范围筛选并排除本人作品后的集合，展示最常见100个标签；更多标签可在原输入框手动填写。追加筛选不会放宽上方条件；范围变化后不再存在的追加标签会清除。参照不足5条时仅作少样本事实对照，不用于综合评分或增长判断。CSV保留查询标签、匹配方式、追加标签、期数及发布时间范围，便于复核。

播放、点赞、评论、收藏、分享、投币和弹幕先展示绝对数量。六维图使用前六项的样本位置，指该指标在当前参照中严格更低的作品占比；并列不算超过。每个维度使用自己的有效样本，不把缺失值填0，不合成综合质量评分。至少三项本人有效指标才画图。

互动/播放比例单独展开。本人不同时间采得、不能配对的指标不计算比例；低播放量时提示比例不稳定。2播放1赞会如实显示50%点赞率，但不会据此获得综合战力第一。

有固定窗口标签的本人指标不与累计参照直接比较。本人作品的相同BV号会从参照中排除。导出的CSV保留来源、时间和精度信息。

## 升级

使用2.5完整包：关闭旧CLab，解压新版到新目录，将旧目录的`local`文件夹复制到新版同名位置，再启动原有Windows或macOS/Linux启动脚本。先保留旧目录作为恢复副本。

使用2.4升级补丁：关闭旧CLab，把补丁内文件覆盖到含`app.py`和`creatorlab`的原目录，然后重新启动。补丁不携带`local`目录或个人数据库，不需重导入已有作品。

参照SQLite及校验清单在`assets/references/`。应用只读打开此库，不向个人账号、作品或实验表写入参照。文件缺失或校验失败时会显示恢复提示，不填充演示数据。

## 开发和数据更新

`tools/build_weekly_reference.py --source <采集数据库>`可从已完成的第292—391期重建同结构资源。工具要求100期均已处理，清单与处理记录数量一致，缺口已复核；输出仅含公开视频元数据、指标、标签、精度和来源，不含账号登录状态。

此功能已通过自动页面交互与隔离测试，尚未在用户Windows机器上进行本次新入口视觉验收。
