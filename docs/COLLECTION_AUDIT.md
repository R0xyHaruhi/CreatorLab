# 采集核查与已知限制

公开文档不附带私人账号调查、作品明细或登录记录。当前验收状态见[发布检查](RELEASE_CHECKS.md)和[实际验证](LIVE_VALIDATION.md)。

- 平台标称总数、源页面可见清单和已入库作品数是不同概念。数量差额不能直接推定为私密或删除作品，也不能视为全量采齐。
- 新作品需要可靠账号标识或用户明确归属确认；不同账号不混合。
- 私密、删除与不可公开记录不参与公开流量排序；缺失指标不填零。
- 封面请求失败、完播率缺失和图文阅读字段缺项分别报告，不将已有记录的存在当作全部字段齐全。
- 需要补采时可使用任务中心；缺失补采不能凭空补回错过的固定观察窗口。
