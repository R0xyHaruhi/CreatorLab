# 战力图与参照口径

入口为「看作品」。顶部横向导航可直接切换战力图、数据详情、作品对比、外部参照和账号总览。选择作品后先看图与直观结论，切换数据详情会保留所选作品。PNG可用「保存战力卡」导出。

## 默认比较

个人历史参照为同账号、同平台、同观察口径的全部其他有效历史作品。默认不按体裁、赛道或年龄自动缩小范围；用户可主动切换同赛道并自行勾选作品分类。

图中数量实线与互动转化虚线各自表达历史位置，不是内容质量总分。轴上满刻度不代表实际完播率为100%；实测百分比另行展示。每项只采用真正有效的观测，缺失保留空白，小样本比例受稳定性规则限制。

视频完播率与图文阅读深度分别适用，B站六轴与抖音口径独立。不能直接比较不同账号相对于各自历史的位置，也不能用累计数反推精确固定窗口。

## 外部学习

B站空间顶部的「每周必看」可直接打开精选库。「外部参照」用于同赛道创作者对比。参照须有来源、时间与样本范围。精选作品的对比结果仅适用于所选样本。人工核实分类与字段有效性后再比较。
