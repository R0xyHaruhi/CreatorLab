## 已知边界

- 抖音登录、验证码、网页改版会影响采集。新作品和归属不明记录需确认。
- 已有作品可自动定时刷新，不需要每天手动点击；服务需保持运行，页面可关闭。
- B站后台定时更新尚未接入。公开页无完播率时保留缺失。
- 没有读到的旧作品或字段保留原观测，不宣称本轮全量刷新。
- 测试机C盘临时空间不足时可将TEMP／TMP和pytest临时目录指向空间充足的磁盘。本轮最终回归使用D盘隔离临时目录，不清理个人文件。
- 缺失不补零，不保证命中精确固定窗口，不回推历史数据。
