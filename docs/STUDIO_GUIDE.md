# 当前工作台指南

CreatorLab当前为个人创作者工作台，入口只有「看作品、做下一条、作品库、同步与设置」，不提供团队／MCN分区。

第一次使用请看[三步上手](FIRST_RUN.md)。功能支持范围见[README](../README.md)，自动更新条件见[自动更新指南](AUTO_UPDATE.md)。

阶段4—6的外部参照、创作方案和复盘见[创作闭环](CREATIVE_WORKFLOW.md)。遇到问题请看[使用与排障](USAGE.md)或[反馈说明](CONTRIBUTING.md)。

旧版说明统一保存在[历史记录](history/README.md)，不代表当前菜单或支持范围。
