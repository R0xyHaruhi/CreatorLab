# 公开到GitHub前

## 生成干净源码包

在项目根目录执行：

```bash
python tools/release.py
python tools/release.py --output artifacts/CreatorLab-2.6.30-beta-source
```

输出目录和同名ZIP只含白名单源码、公开文档、示例与必要资源，并附SHA256文件清单。工具拒绝覆盖已有输出。只上传生成的干净目录，不上传日常使用的整个项目目录。

工具会排除个人目录、调试产物、私有文档、虚拟环境、运行日志、个人数据库和浏览器会话；唯一允许的数据库为随项目公开的精选参照库。作者署名、技能和资源许可证保留。打包失败时只报告文件与行号，不打印疑似秘密的值。

## 实际提交清单

新建Git仓库并暂存文件后执行：

```bash
python tools/release.py --tracked
```

这一步检查Git实际跟踪文件，不能用.gitignore代替。不要强制添加被忽略的个人文件。当前工作目录未初始化Git时，这一步会明确失败；纯源码白名单检查仍可独立运行。

仓库工作流在Windows/Linux Python 3.12运行测试及发布检查。推送前本地验证，推送后再确认远端CI确实通过；不将工作流文件存在当作CI成功。

当前为Beta。对外公开列出已验证和未验证的范围，尤其是24小时持续更新、其他账号、其他系统与网络环境。真实跨天观察未通过前不标稳定版。当前状态统一见[发布检查](RELEASE_CHECKS.md)。
