# 使用和排障

先选择平台。首次使用可看示例或添加账号。抖音采集后先在同步区下方核对批次，确认具体账号才写入作品库，不需要手填各项指标。

每个抖音账号使用独立采集浏览器目录。采集期间出现多个作者标识会暂停保存；无法识别作者时，通过作品预览人工核对。重复确认同一批次不会重复建作品。人工核对不被表述为自动验证登录身份。

| 现象 | 处理 |
| --- | --- |
| Python版本不匹配 | 安装64位Python 3.12；本批锁定依赖已发现不兼容3.11 |
| 首次安装失败 | 检查网络，运行 `repair_windows.bat`；详情在 `local/install.log`，不需删除作品数据库 |
| 8501被占用 | 启动脚本会选可用端口，以打开的网址为准 |
| 重复启动 | 脚本优先打开同目录已运行实例；旧版直接启动的服务可能需手动关闭 |
| 没有采集浏览器 | 同步与设置 → 备份与诊断 → 安装导入浏览器，或运行浏览器安装BAT |
| 登录或验证 | 在独立采集窗口完成，不把密码或Cookie复制进工作台 |
| 采集后作品没变化 | 检查同步区下方“待核对的抖音采集”，确认归属并入库 |
| 窗口中断 | 重开可核对已暂存批次；再次同步更新同一视频，不等于精确恢复页面位置 |
| 有播放却没有完整画像 | 检查精确发布时间、真实观测时间、同期互动；至少3维和3条同组作品才可探索 |
| 完播始终空白 | 需要创作者数据，公开页不提供时不能补算 |
| CSV导入0条 | 同账号相同文件已导入会跳过；修改数据后可重新导入 |
| CSV校验失败 | 检查重复ID/表头、字段单位和时间；先用模板，最多10MB、5000行 |
| 数据库打不开 | 关闭应用和采集窗口，运行 `recover_windows.bat`，选备份ZIP或 `local/backups` 中的DB |
| 退出采集账号 | 停止全部采集，在备份与诊断中勾选清除登录态；作品保留 |

## 备份

每天首次启动保存一份每日备份，保留最近7份。升级、CSV、入库和恢复前的保护副本不自动清理，存放在数据库同级 `backups/`。需要释放空间时手动归档旧保护副本，不要删除唯一可恢复副本。

界面恢复接受备份ZIP；离线恢复也接受自动备份DB。当前文件损坏时先移入 `backups/damaged-*`，恢复失败尝试放回。恢复只允许支持的数据库版本。

程序ZIP与数据备份不同。数据备份含作品、分类、封面、实验和待核对批次，不含浏览器登录目录或仅存在会话中的模型Key。

## 诊断和可选组件

脱敏报告只含版本、系统、数量、字段覆盖和任务状态，不含标题、账号ID、原始日志和登录信息。原始本地日志未经检查不要公开上传。

锁定依赖包含本地FFmpeg运行支持，用于视频规则检查和抽帧，也可手动提供关键帧。关闭AI时不调用模型，点击对应AI按钮才发送所需内容；素材复盘另需勾选同意。

## 自动更新与完整备份

抖音可在同步与设置开启已有作品定时更新，运行条件见[自动更新指南](AUTO_UPDATE.md)。登录失效会暂停，不会自动处理验证码。

主库ZIP不包含工作流附属库和自动更新设置。迁移前关闭程序，备份主库、同名工作流附属库及个人封面；也可单独导出工作流JSON。自动更新配置绑定原数据库路径，迁移后重新启用。登录目录和密钥不要随公开源码分享。
