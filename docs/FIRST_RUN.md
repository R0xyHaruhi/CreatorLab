# 第一次使用CreatorLab

## 安装并打开

1. 安装64位Python3.12并包含Python Launcher，解压源码到可写目录。
2. 双击 `start_windows.bat`。首次启动会创建独立环境并联网安装依赖。窗口会显示当前下载文件、可获得的下载量、等待时间和校验阶段。若安装失败，可按窗口提示重试。
3. 页面打开后可以先点「先看可视化示例」，无需登录，示例不写进个人作品库。

日常还是双击相同脚本，依赖正常时不会重复安装。网页可以关闭，程序和自动更新依赖启动窗口保持运行。

## 添加自己的第一条作品

在「看作品」选择平台同步、导入 CSV 或手动录入。保存账号后会继续所选方式。CSV 和手动录入成功后可点击「查看刚导入的作品」。

- **抖音**：第一次只需给账号起一个便于区分的昵称，不必先找账号ID。选择同步，在独立窗口登录；如果提示待确认，在同步区核对归属并入库。
- **B站**：填写自己的UID或空间链接，导入公开投稿。登录和验证码需要你处理。
- **已有表格**：在「同步与设置 → 账号与文件导入」下载CSV模板，预览后确认导入。
- **暂时没有表格**：同一页面展开「手动添加一条作品」，填写标题和已知指标即可；未知字段留空，不用填零。

发布时间可以留空，也可以填 `2026-10-26`。需要固定窗口复盘时，请填写带时区的时间，例如 `2026-10-26T12:00:00+08:00`。已有的无效日期会标为「发布时间待确认」，可在作品库的「作品详情」纠正。

## 只看同步页顶部这张卡

| 显示 | 意思 | 下一步 |
| --- | --- | --- |
| 已入库作品 | 已写入本机库、可查看的作品 | 去“看作品”选择一条 |
| 待确认新作品 | 已读到但还没确认账号的新ID，重复批次不重复计数 | 在下方核对并确认，不必重新扫描 |
| 最近入库更新 | 最近一次写入作品库的时间，按本机时间显示 | 各指标真实观测时间仍以报告为准 |
| 自动更新已暂停 | 登录、验证码或归属条件未满足 | 手动处理后保存自动更新设置恢复 |
| 本轮更新未完成 | 本轮没完成，不等于已有数据丢失 | 展开任务详情查看原因，再继续 |

读到多少条不等于已入库多少条，也不等于平台全部作品数量。无足够历史数据时，可以看原始指标；战力图需要有效历史参照，平台不会伪造评分。

安装失败可运行 `repair_windows.bat` 并查看本机 `local/install.log`。不要公开原始日志、登录会话或整个工作目录。恢复数据见[使用与排障](USAGE.md)。

如果同步提示没有采集浏览器，到「同步与设置 → 备份与诊断」安装导入浏览器；这不影响先看示例或手动／CSV导入。
