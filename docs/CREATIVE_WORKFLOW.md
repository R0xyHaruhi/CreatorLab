# CreatorLab 阶段4—6使用指南

看见创作力，让每次尝试都有依据。

本轮在2.6.13源码上增量实现外部参照、创作方案和实验反馈。战力卡指标计算、数量／转化双线、图文阅读深度、采集及既有个人数据库结构保持原有规则。89条作品差额未处理。

## 阶段4：保存与更新外部参照

1. 切换到B站空间，打开「看作品 → 每周必看」。
2. 选择自己的作品，以公开标签、期数、发布时间和必须同时命中的标签细分候选。先查看样本来源与内容，再确认赛道；标签相同不等于内容可比。
3. 开启「保存或更新细分赛道参照」，选择分区、细分赛道和已核对的作品，填写范围名称并确认。保存后，创作助手可按同账号、同平台及已确认细分赛道引用。
4. 需要新数据时选择1—10个已收录BV号，点击「读取最新公开计数与标签」。仅更新所选作品的当前累计计数、标签和观测时间。失败即停；未成功样本保留旧快照，最近更新记录会显示成功、失败和未尝试项。

内置第292—391期4,600条有效作品保持只读及哈希校验。本地更新单独叠加，不改写内置库，也不导入个人作品。来源、观测时间和精度随样本保留；少于5条仅作具体作品学习。精选热门样本不代表全站用户，不能据此声称超过全站多少用户。更新个别作品不表示整库已刷新，也不会自动收录新一期节目。

抖音不使用B站精选数据。可在「做下一条 → 其他创作工具 → 分类与深入分析 → 成长面板 → 学习对象」保存经人工核验、同平台同赛道、来源可核实的近期参照。符合观察窗口和积累时长条件的人工参照，可在创作助手中选择；样本数由录入者核对，不假称全站样本。

## 阶段5：从实际数据生成方案

打开「做下一条 → 准备创作」，选择账号、目标和作品。

- 个人依据默认当前账号、当前平台的全部历史有效作品，并排除当前作品，不自动按赛道、年龄或体裁分组。只有主动切换「同赛道（按已确认分类）」后才按分类对比；可自行勾选作品标注。各指标分别统计有效值，视频完播率与图文阅读深度保持各自适用规则，缺失不补零；累计与固定窗口仍分开。
- B站可以引用已保存的同赛道参照；累计精选数据不与24小时／7天／30天固定窗口混用。
- 展开「观察事实、来源与样本限制」，查看个人、外部作品和复盘经验的证据编号、数值、来源与观测时间。
- 五类方案覆盖选题、标题、封面、内容结构和跨平台复用。每项列明具体改动、待验证假设和依据。未提供实际素材时不声称看过封面或内容；跨平台只引用手动关联版本，不合并两平台评分。
- 先在「这次先改哪一处」选择一个方向，点击「保存并开始验证」，保留完整证据并进入对应实验。历史方案与JSON导出在「历史方案、导出与备份」。同一方案同一类型重复点击不会重复建实验，也不会覆盖已有复盘。

默认仅使用本地规则，不请求模型。DeepSeek、豆包、Ollama和OpenAI可选；先看文字摘要，再明确同意并点击生成才发送。模型只提出待验证建议，不改写本地观察事实。未知证据引用、不完整分类和明显增长保证会被拒绝。配置步骤见[中文教程](AI_CN.md)。付费模型未在本轮使用个人密钥实测，接口路由和响应处理通过模拟测试。

## 阶段6：按窗口实验、复盘与反馈

1. 从方案转成实验，或在「做下一条 → 记录与复盘」新建一次挑战。
2. 选择原做法与实施改动后的作品，选择相同24小时／7天／30天窗口，点击「关联并检查窗口」。作品不能重复，不能跨账号、平台、体裁或不同已确认细分赛道。部分已分类、部分未分类也需先核对。
3. 只有当时真实记录的固定窗口数据可用于比较。错过窗口不能用今天累计值回推；目标指标或有效时间配对缺失时继续等待，不填零。首次可复盘时冻结参照证据。
4. 记录本次目标、实际改动类型与内容、干扰因素、探索性经验和下一轮动作。少于5条明确为小样本探索；更多样本也不是随机实验，标题、封面、发布时间等差异不证明因果。
5. 数据可比、全部作品已确认相同赛道、进度为「已复盘」，并填写经验及下一轮动作后，可勾选「将这条已复盘经验反馈到下一轮创作建议」保存。
6. 下一轮创作助手只引用相同账号、平台、体裁、赛道和目标指标的有效经验，展示原实验窗口及两组样本数。取消勾选后保存可撤回；改动关联作品、窗口或赛道后，旧反馈不再适用，需重新关联与复盘。

图文继续使用独立阅读深度，不用残留视频完播率替代。创作方案可以建议图文结构；固定窗口没有真实可用的目标观测时，不能将图文阅读效果宣称为已验证。

## 保存位置与备份

新增参照、更新记录、方案、结构化复盘和经验保存在主数据库旁边的同名附属文件。例如主数据库为 `local/creatorlab.db`，附属文件为 `local/creatorlab.workflow.sqlite3`。应用不会用打包数据覆盖个人数据库、封面或登录配置；用户点击保存实验仍按原流程向自己的实验表追加或更新记录。

创作助手和参照管理中的「创作工作流记录备份与恢复」可导出当前账号记录。导入先校验格式、校验值、账号身份及作品／实验对应关系，预览后只补入缺失项，不覆盖已有记录。导入的经验先停用，需要重新复盘确认。

现有主数据库ZIP备份不自动包含新附属文件。搬迁或备份整个项目时同时保留这两个数据库；或先分别导出主数据库备份和当前账号工作流JSON。不要上传密钥、浏览器会话或登录配置。
