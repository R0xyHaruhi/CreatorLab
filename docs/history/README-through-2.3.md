# CLab Creator Hub — 1.0 Preview

**面向中国个人创作者的本地、开源、多平台作品工作台。** 首批支持抖音和 B 站，尚未支持自动发布、B站自动账号授权、云端数据同步。

## 新版有什么

- 统一账号：一个 CLab 工作台可添加抖音和 B站个人账号。
- 统一作品库：按平台筛选，保留每个平台的作品 ID、来源、更新时间与指标快照。
- 内容项目：手动关联同一作品的抖音版 / B站版，展示有限的跨平台对比。
- 易读的数据：播放量万/亿格式、比例显示百分比、时长显示秒。
- 作品分析：播放分布、中位数、Top 10，数据不足时明确提示。
- **保留旧版功能**：`pages/98_旧版工具.py` 继续提供抖音网络采集导入、旧 AI/实验/团队工具；采集扩展仍在 `chrome-extension/`。
- 初始不自动加载模拟作品，避免污染真实数据。

## Windows 运行

需要 Python 3.10+。解压后双击 `start_windows.bat`，打开 `http://localhost:8501`。或手动运行：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

**保留旧数据：** 关闭旧版后，备份旧版 `local/creatorlab.db`，将副本复制到此项目的 `local/creatorlab.db`，再运行新版。新版增加独立的 `hub_*`、`clab_*` 表与兼容字段，不删除旧版数据。**不要直接覆盖唯一的数据库副本**。

若继续使用原有抖音 Chrome 扩展：双击 `start_import_bridge_windows.bat` 启动本地接收服务，然后在左侧「旧版工具」中复制密钥。注意：扩展并未被整合进 CLab 安装包，仍需单独在 Chrome 加载；这不是零安装同步。

## 首次使用

1. 在「添加账号与导入」建立抖音和 B站账号。
2. 手动添加作品，或下载 CSV 模板导入。CSV `title` 必填，其他支持字段：`external_id,published_at,url,views,likes,comments,shares,favorites,completion_rate,completion_rate_5s,bounce_rate_2s,avg_view_proportion,avg_view_second`。
3. 旧版抖音数据用户可点击「导入现有抖音作品记录」，将 `creator_center_videos` 纳入统一作品库。
4. 在「内容关联」创建一个内容项目，把同一个视频的抖音/B站发布版本加入项目。
5. 在「数据分析」查看表现分布、中位数、Top 10 与数据可用性提示。

### 真实限制

- B站支持浏览器辅助的公开空间与可选本人创作中心采集，也保留手动与CSV导入；成功范围取决于页面、登录状态和可见权限，见最新升级说明。
- 抖音旧版 Chrome 扩展仍为可选的实验性辅助导入方式，不保证页面兼容性；请仅在自己有权访问、且符合平台规定时使用。
- 没有私自同步竞品博主或声称取得未授权的后台数据。
- 不把不同平台的完播率等口径不同的指标直接合并评判。
- 本版是面向使用体验的 GitHub 预览版，不是已交付的 Windows 原生安装程序。

## 数据结构

使用单一本地 SQLite：`hub_accounts` → `hub_posts` ↔ `hub_projects`；`hub_snapshots` 存储每次导入指标的记录。原有 `creator_center_videos` / `creator_center_metric_history` 表保持原样。无视频 ID 的人工作品不会按标题自动去重。

## Creator Analytics Preview — 个人创作者驾驶舱

新增「🔎 创作者驾驶舱」：账号与发布日期筛选、数据覆盖率、播放量分布和分位数、发布节奏、每周作品表现、历史快照、留存指标、互动/播放比、双向作品排行、已确认跨平台内容对比、同名跨平台关联候选、数据证据驱动的行动建议和可下载文字报告。

**自动导入范围：** CLab 启动时会自动检查**本地** SQLite 中已有的抖音创作者中心采集作品，将新的或更新的记录同步到统一作品库；左侧也能手动重新同步。无需逐条录入、不需先填账号 ID，重复导入不增加相同快照。这个功能**不是**抖音在线自动登录、后台自动采集或 B站自动同步。浏览器扩展依然需要用户主动操作，且必须遵守平台规则。

**重要口径：** 播放量为最后一次快照中的累计播放；按发布时间分组并不是获取该周新增播放；跨平台的留存率不能视为等价；互动/播放比为计算指标而不是各平台官方互动率。没有指标就隐藏相关图表，不会生成演示数据冒充真实数据。不能以相关性断定原因。

**隐私与历史数据：** 仍使用本地 `local/creatorlab.db`，升级之前备份数据库。不要把 `local/`、密钥或账号 Cookie 上传 GitHub。

## v1.2 试验性集成浏览器同步（路线 B）

- 启动 CLab 后，在左侧 **「抖音 · 集成浏览器同步」** 点击「打开抖音同步窗口」。
- 系统优先使用 Windows 安装的 Microsoft Edge；如果找不到，会尝试 Playwright Chromium。后者可能需要先执行 `python -m playwright install chromium` 下载浏览器（在 `.venv` 环境下执行）。
- 请在独立浏览器窗口**自行登录**抖音创作者中心，然后打开「作品管理」。CLab 监听页面自然产生的 `work_list` 响应并保存可解析的作品指标；之后有限地使用界面滚动 / 下一页按钮；不会主动请求未公开接口。
- 回到 CLab 侧边栏点击「刷新进度」，查看抓取量和后台报告总数。点击「停止同步」可停止。采集到的数据实时写入 `local/creatorlab.db`，自动进入分析工作台。
- **仍是 Beta 原型**：目前不能保证完整采集 292 条或能通过平台所有登录场景；没有对真实抖音账号完成端到端验证。自动化浏览器与平台的使用须符合其规则。若账号登录、验证码、图形界面变化等导致失败，不会尝试绕过。
- 登录态在 `local/douyin_browser_profile` 中由浏览器保存，请妥善保管该目录（包含敏感会话数据），不要上传到 GitHub、发送给他人或共享备份。退出 CLab 不会自动清除浏览器登录态。
- B站暂未提供自动同步；既有扩展仍可作为回退。

## v1.3 Creator UX Preview

- 主导航按日常使用优先级整理：首页、作品库、数据分析、内容关联、创作助手、账号与同步。

- 将难懂的中位数平台比较从首页移除；流量分析改成明确播放区间、作品数与可点击原作品的封面列表。

- 保留原来的集成浏览器采集、原始数据、旧版工具及数据库迁移功能。尚未验证实际抖音 292 条作品的全量采集，也未实现 B 站自动同步。
