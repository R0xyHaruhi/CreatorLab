# CreatorLab 2.6.17

新增视频体检入口。先检测本地原视频的黑场、静止、静音及较长未切换区段，显示最多3处回看候选；支持跳转回看、标记有意安排、保存及导出检测记录。

检测后默认不使用AI。用户可选择模型、预览关键帧和文字、明确同意后请求更细分析，也可以导出材料包给自己的AI或agent。第一版AI只读取预览素材，不发送整段视频，不声称完整理解视频或证明流失原因。

新增固定依赖 `imageio-ffmpeg==0.8.1`，包含本地检测所需组件。第一次升级需要更新依赖，已有安装可运行 `repair_windows.bat`；后续本地检测离线可用。视频第一版限200MB、10分钟。

个人数据与工作流附属数据库需保留，不覆盖 `local/`。体检结果进入附属数据库并纳入工作流JSON备份；原视频不持久保存。详细范围、使用方法和限制见 [视频体检指南](../../VIDEO_INSPECTION.md)。
