# 2.6.4：抖音一键同步试用

## 本轮新增

- 「一键同步抖音作品」打开账号专属的本机浏览器目录，复用已有登录会话。
- 自动识别并点击可见的「内容管理」「作品管理」「视频管理」入口；只操作抖音官方创作者中心页面。
- 列表读取成功后按账号记住管理页；下次优先直接打开。只保存不含查询参数的页面路径，不导出Cookie、密码或登录令牌。
- 登录或验证码需要用户完成，随后自动继续。入口变化找不到时明确提示手动进入一次，不反复点击。
- 首次人工核对入库后，记住实际捕获的作者标识。后续每条作品的作者标识均匹配才自动更新。没有作者标识、作者发生变化、用户停止或异常中断时仍保留待核对，不猜账号归属。
- 自动更新前保留数据库保护副本；失败恢复原数据，采集记录仍可核对。

## 当前边界

这是自动导航试用版。自动状态与采集/入库链路已用模拟页面和本地数据库回归；尚未在用户Windows上的真实抖音页面验证新导航。

本轮没有加入定时后台采集或增量快速模式，仍按现有完整列表逻辑采集；不保证完全无窗口、免登录或免验证码。作者字段可能未由平台返回，此时仍需核对归属。

2.6.3实测已更新入库204条、133张公开作品封面、120条完播率；页面到底但平台总数293，差额89条尚待核实。总览只有32条符合公开分析条件，其余172条仍需核实。本版不把自动导航或自动入库当作数据已经采齐。

## 安装与验收

1. 关闭CLab，将压缩包全部解压覆盖到app.py所在目录，再启动。
2. 抖音空间 → 展开「抖音同步」→ 点击「一键同步抖音作品」。
3. 首次或登录过期时，只完成登录/验证；观察是否自动进入作品管理。无需预先手动切换页面。
4. 等采集结束核对实际条数、缺项、封面、归属和入库状态。首次作者核对后，下一次再同步检查是否直达和自动更新；作者字段缺失时应保持待核对。

安装包保留战力卡、100期精选参照、2.6.3标题/平台隔离/筛选重置修复。不含个人local数据库和浏览器登录目录，不覆盖已有登录会话。

## 本轮验证记录

- 全量回归218项通过；2条既有空样本均值警告。
- 导航与自动更新专项15项通过，覆盖首次菜单导航、验证码暂停、按账号记忆页面、首批核对后自动更新、错账号/缺作者不自动入库及失败恢复。
- Python模块语法及导航DOM脚本语法检查通过。
- 以上不等同于Windows真实抖音页面验收，待覆盖后继续检查。
