# CreatorLab 2.6.15

个人历史参照默认使用当前账号、当前平台的全部历史有效作品，排除当前作品自身；不自动按赛道、作品年龄或体裁分组。战力卡维持此规则，作品报告和创作助手移除原先自动缩小个人参照范围的限制。

需要特定内容对比时，用户主动选择同赛道，展开分类入口，勾选作品并标注分区、细分赛道后比较。标注分类本身不改变默认全部历史模式；未确认分类不会被自动归组。

旧分析页也默认保留不足7天与发布时间未知的有效作品；旧成长画像不再自动按年龄、体裁缩小参照。完播轴将“历史100/100”改为“高于13/13条”这类实际作品条数表述，同时保留实测完播率，避免被理解为100%完播或作品满分。

全部历史不等于每轴都使用相同样本数。播放、点赞、完播率等各自只使用有真实有效值的作品；图文不使用视频完播率，视频不使用图文阅读深度。界面同时展示范围总参照数及每项指标的有效数，缺失不补零。累计与固定窗口、个人与外部样本、两个平台继续隔离；已由用户选择作品关联的固定窗口实验规则保持。

版本由标题下方显示。更新应用文件并刷新页面即可；不覆盖 `local/` 个人数据库、封面或登录配置。
