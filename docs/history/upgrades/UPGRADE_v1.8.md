# CLab 1.8 · 创作成长游乐场（试验版）

这轮将数据分析做成“看懂作品优势 → 发现细分赛道 → 选择学习对象 → 做一次创作实验”。原有图表、两条作品对照、按分类比较、跨平台关联和手动导入仍保留。

## 怎么开始

关闭旧服务，备份并复制旧 `local` 文件夹到新包，再运行 `start_windows.bat`。进入 **数据分析 → 成长面板**。没有AI配置也可以使用六维图、标题规则建议、手动赛道、参照数据录入和创作挑战。

## 六维作品卡

- **B站**：播放触达、点赞比例、评论比例、收藏比例、分享比例、投币比例。
- **抖音**：播放触达、点赞比例、评论比例、收藏比例、分享比例、完播率。
- 选择一条作品，查看六边形图、原始数值与参照样本数；可叠加同发布时长区间的另一条作品。
- 分数是该作品在**同账号、同平台、同作品年龄区间历史记录中的相对位置**，不是同行排名或内容质量的绝对评分。并列值平分位置；全部相同得到50，而非100。
- 每一轴至少5条有效记录。缺失轴不补0、不补造多边形，没有综合总分。参照样本更新时旧作品的相对位置可能变化，不是固定终身等级。
- 给出相对优势和一项可以测试的维度，不保证修改后增长。年龄区间内仍有累积时长差异，分字段数据也可能来自不同采集时刻。

## 分区与赛道地图

CLab提供按平台定制的分析标签，不宣称完全复制当前官方分区。

- B站：生活、游戏、动漫、知识、科技、美食、时尚、音乐、舞蹈、运动、影视、动物自然、鬼畜、汽车、其他等。
- 抖音：生活、游戏、二次元、知识、科技数码、美食、美妆穿搭、音乐舞蹈、搞笑剧情、运动健身、旅行、萌宠、三农、汽车、摄影剪辑、亲子家庭、其他等。
- 例如游戏进一步分为游戏直播回放、直播切片、资讯、攻略、操作高光等。本轮分析视频投稿，不采集直播间实时数据。
- 可先使用明确标注的标题关键词规则；或启用AI，点击“AI分析作品赛道”。AI每次最多分析60条标题，**没有观看或理解视频画面**。
- AI只接受合法赛道和能在原标题中找到的证据片段；结果可修正。手动确认不会被后续规则或模型覆盖。
- 手动先选分区，再选细分，批量确认作品；也可设置账号的学习对标赛道。
- 圆环图同时展示已识别赛道和未知部分。分别显示“识别覆盖率”和“已识别部分的同赛道占比”，不将少量已识别作品的100%误写成整个账号100%垂直。

## AI设置

成长面板可选择本地Ollama或OpenAI，填写模型名称。OpenAI Key可通过当前页面密码输入框或本机环境变量提供；输入框内容仅保留在页面会话，不写入作品库和发布包。点击AI按钮才发送作品标题与赛道标签，不发送视频、封面、浏览器Cookie或整个数据库。外部模型可能收费；不会静默切换到云模型。

## 学习对象与差别比较

1. 根据已识别赛道建议当前学习方向；没有识别结果时，选择框只作为可修改起始项。
2. 点击AI推荐最多3个学习对象候选，或手动填写你认可的创作者主页。
3. **AI候选未进行实时网页核验，不是经过验证的头部排行榜**，候选身份、赛道与学习价值需要打开主页检查。模型不能提供粉丝/表现数字充当真实基准。
4. B站候选可点击“采集这个B站参照的真实公开作品”，复用浏览器导入，收集公开列表和最近50条详情。采集失败仍会标明，不能以按钮已点击当作成功。
5. 参照账号被单独标记，不进入个人作品总量、首页播放总计或自己的六维评分。若UID原本就是个人账号，不会自动转成外部参照。
6. 实采后，手动确认哪些参照作品属于当前细分赛道；双方同平台、同细分赛道、同发布时长各有5条，才显示共同有效指标的中位数对照。
7. 两平台都可手动填参照数字。必须注明样本数、采集日期、来源和作品年龄范围；数据90天以内、至少5条、范围相同才进入数值比较。来源是用户录入，不冒充平台验证。
8. 原始粉丝规模只作背景，不把与大账号的差距转成你的“失败分数”。目前抖音外部参照未实现自动公开采集，保留候选、平台搜索和手动参照。

## 创作挑战

写下一个准备改变的做法，把挑战标成“计划中 → 制作中 → 已发布待复盘 → 已复盘”，保存发布第7天的结果和心得。记录保存在本地数据库；完成进度由用户更新，不自动宣称实验成功，不用日更次数、虚构XP或保证爆款制造激励。

## 封面与手动数据

- 原有封面截图缓存保留。同步末尾对仍缺失但已取得实际地址的封面，尝试用浏览器从允许的平台图片域加载原图并缓存。
- 限定图片资源和平台图片域；不任意请求用户输入的网站。失败时保留缺失状态，作品库仍可上传原封面。
- B站导入显示真实封面缓存数量。URL过期、防盗链、站点改动或主动停止，都可能导致个别封面无法取得；不生成假封面。
- 手动添加作品补充评论、分享、收藏、完播；B站额外支持投币、弹幕，空值仍保持未知。原有CSV导入与自由表现形式分类继续保留，与新的分区/赛道标签并存。

## 验证边界

测试覆盖六维分位数、缺失值、作品年龄隔离、手动分类保护、AI标题证据验证、模型候选不能注入数字、参照账号隔离、封面域名约束、缓存、成长页面操作和挑战持久化。

尚未在真实登录页面对封面补取、参照采集完成在线验收；也没有完成浏览器截图视觉验收。现阶段是可运行的成长分析试验版，不能声称已具备多模态视频理解、全网实时赛道发现或官方头部榜单。
