# 2.6.2 实际浏览器验收与修复

本轮通过连接的Chrome访问用户本机127.0.0.1:8501，而非仅运行自动测试。

实际确认：主标题完整显示；战力挑战一级入口、数量综合位置、PNG保存按钮存在；B站overall表显示已导入的播放、点赞、收藏、评论、投币等真实记录。

实际复现：从抖音切至B站后，已挂载选择框仍显示抖音标题，下方报告却使用B站记录。这是前端选择框身份复用，不能仅通过后端options过滤检查。
修复：作品、报告、比较、账号筛选和分类下拉框按平台使用不同的浏览器控件身份，同时保留跳转使用的模型字段；新增身份与跳转回归检查。

实际复现：278/约68.69万的评论比例被显示为0.0%。报告及overall改为两位百分比，极小非零值显示<0.01%，不冒充0。

真实采集：启动一次B站快速公开导入，任务进入等待列表/登录/验证阶段，未读到新作品。已请求停止；未证明在线采集完成，未证明有数据情况下的中断恢复。没有操作验证码。

待用户安装后复验：本机代码位于用户Windows目录，当前网页连接不能直接覆盖该目录。请关闭CLab，将修复覆盖包全部覆盖到含app.py的目录再启动；随后继续在同一浏览器检查平台切换。采集源窗口的实际提示仍需查看。
