# CLab 1.5 · 看懂重点，再决定下一条怎么做

这轮修复对应：背景与控件配色不一致、分析页不知从何看起、创作助手堆叠统计术语。

## 升级

1. 停止旧版服务，备份旧版 `local` 文件夹。
2. 完整解压新包，将旧 `local` 文件夹复制到新目录下。
3. 从新目录运行 `start_windows.bat`。本轮调整了依赖最低版本，启动脚本会安装所需依赖。
4. **必须关闭旧服务再启动新包，不能只刷新旧页面。** 新主题由 `.streamlit/config.toml` 提供，解压时保留这个目录。
5. 如果曾在 Streamlit 右上角 Settings 手动指定 Light / Dark，请选择应用的 Custom Theme。原来的应用内浅色/深色选择器已移除。

数据库沿用1.4结构，账号、作品、分类标签、封面缓存和历史快照保留。

## 统一柔和深色

- 背景改为低亮度炭灰，正文使用灰白色；主色为低饱和薄荷绿。
- 移除只覆盖部分背景、全局强制文字色的旧CSS，避免浅色背景与黑色控件混搭。
- 使用 Streamlit 原生主题管理侧栏、菜单弹层、输入框、按钮、表格和提示框。图表跟随原生主题。
- 图表隐藏默认工具栏、使用透明背景。高级图表仍支持鼠标查看具体数据。
- 文字层级与页面宽度收紧，减少一屏内的大量数字。

## 数据分析的新顺序

| 页面 | 先解决的问题 |
| --- | --- |
| 先看重点 | 当前能判断什么、值得先看哪条作品、下一步怎么用 |
| 对照两条作品 | 将一条表现较高的作品与相近范围内的日常作品对照，找一个可复用的做法 |
| 按内容找规律 | 分组后比较日常表现；时长、发布时间、角色与质量散点图按需要展开 |
| 跨平台复用 | 同一内容在各自账号上，相当于日常表现的几倍 |

开始时只选择账号与目标，例如“找到值得继续做的内容”“让观众多看一会儿”。细节范围放在折叠区。

- 全部未分类时：说明还缺什么，提供分组入口，不画未分类箱线图。
- 分类图：改为直观横条、中文数值与样本数，不把Q1、Q3和异常值边界放在主页面。
- 每张主要图表旁写明“怎么用”，原始数据放进详细区。
- 比例以百分比呈现，不再要求用户自行换算0.05为5%。
- 不足样本、缺失目标数据、刚发布和未知发布时间都分别说明，不自动生成优劣结论。

## 创作助手的新顺序

一次给一个优先任务：

1. 为什么先做这件事：引用具体作品或可比分类的实际表现。
2. 先打开哪条：展示作品标题和可用的原作品链接。
3. 下一条具体怎么改：按确认的赛道设计一个待验证的做法。
4. 怎么复盘：记录发布第7天的同一指标，连续做3条再看。

原来的“显著高播放”“中位数判断日常表现”“Q3+1.5×IQR”等通用卡片不再堆在助手主页面。无赛道信息时不默认把用户当COS账号；无充分数据时不冒充确定诊断。

可以在助手中写一句开拍笔记，仅在本次页面会话保留，尚未提供持久化任务管理。

## 保留的分析边界

- 分类效果结论需同账号、同平台、同赛道和同作品年龄区间内两类各至少5条；年龄区间内仍有累积时长差异。
- 作品对照是观察线索，不证明选题、开头或封面导致数据差异。
- 历史累计值不能直接当作发布第7天基准；要通过后续采集建立固定窗口的对比。
- 赛道实验方案为可解释的规则建议，没有新增视频理解模型或实时热点库。
- 封面采集沿用1.4，不对这轮UI调整宣称额外的线上采集成功率。
