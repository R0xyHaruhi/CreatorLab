# CLab 1.6 · B站公开作品一键导入（试验版）

## 使用方法

1. 关闭旧服务，备份并复制旧 `local` 文件夹到新包，再运行 `start_windows.bat`。
2. 侧栏选择「B站空间」，打开「B站作品 · 一键导入」。
3. 填写自己的数字 UID 或完整空间链接；已有数字 UID 账号会默认带入第一项，可修改。
4. 点击「一键导入B站作品」。软件启动独立浏览器并打开视频投稿页，尝试自动翻页和写入作品库。遇到登录、验证码或风控时，在该窗口内处理；不绕过验证。
5. 回到 CLab 点击「刷新作品库」查看进度与结果。可随时点击「停止导入」，此前采集的数据保留。

默认尝试使用电脑上的 Edge 或 Chrome；两者均不可用时使用 Playwright Chromium。若提示浏览器启动失败，先运行一次 `start_windows.bat` 安装依赖，再双击 `install_bilibili_browser_windows.bat` 安装导入浏览器。

## 导入什么

- 正常页面加载得到的公开视频投稿：BV号、标题、作品链接、发布时间、视频时长与封面。
- 列表返回精确播放量和评论数时一并保存；“1.2万”等缩写展示值不会冒充精确整数。
- “补充最近50条的点赞、收藏、分享”默认关闭。开启后会依次打开最多50个已导入作品页，尝试补充页面返回的互动指标；可能耗时较长，失败则保留已有列表记录。访问页数不等于补全成功数。
- 封面优先缓存正常渲染的对应投稿缩略图。未加载或无法明确对应BV号的图片不强行绑定，远程地址也可能失效。
- 弹幕数不当作评论数；公开空间没有提供的完播、留存、收入或后台专属指标不推算。

## 账号与重复导入

导入按UID定位B站账号，首次读到作品时自动建账号。已有账号名称保留；同账号同BV号更新同一条作品，未变化的指标不再新增快照；新指标不覆盖旧的已知指标为空值。手动分类、主题和已填写的时长保留。不同UID的作品不会合并到一个账号。

分页响应必须来自允许的B站域名和投稿路径，并与填写的UID一致。补充详情还校验UP主UID，过滤其他作者。页面卡片兜底只读取目标空间视频投稿页的作品卡片。

## 完成状态

- **公开投稿已导入**：读取到的作品数达到列表报告的总数。
- **已保存部分作品**：页面中断、分页未确认或达到上限；保留已有作品，可重新导入补全。
- **没有公开投稿**：列表明确报告总数为0。
- **需要处理**：没有读到作品、浏览器启动失败或页面加载失败，不假装完成。

单次最多5000条、200次下一页操作，等待列表最长10分钟；可选详情阶段另计时间。不支持自动后台运行的定时任务、私密稿件或合集里的其他作者作品。

## 隐私与实现边界

这是用户发起的浏览器辅助导入，监听页面正常加载的响应并使用可见翻页按钮，不重放签名接口，不导出Cookie。独立浏览器会在本地 `local/bilibili_browser_profile` 保存登录状态；不要把 `local` 上传GitHub或分享给别人。

测试覆盖输入校验、分页适配器、BV去重、指标映射、分类保留、任务互斥、模拟浏览器的两页导入到数据库和按钮启动。测试使用构造数据，不是B站真实在线响应验收。站点响应格式、页面选择器和分页样式发生变化时仍可能失败；本版本尚未用你的真实UID完成在线验收。

明暗切换、已有图表、抖音导入、B站CSV/手动导入均保留。
