# CreatorLab 2.6.21：自动更新已有作品

这是平台内置的定时更新功能。当前先支持抖音，不需要每天点击同步。

## 启用一次

1. 打开「同步与设置」，选择抖音空间。
2. 展开「自动更新已入库作品」，选择账号。
3. 开启「启用自动更新」，选择每天一次、每12小时或每6小时，点击「保存自动更新设置」。
4. 首次更新将在一分钟内启动；此后显示上次成功、下次计划与暂停原因。

本机工作台启动窗口需要保持运行。关闭网页不影响后台调度；退出程序或电脑关机后不再安排下一轮，已启动的一轮可能完成。再次启动工作台后，错过的计划只执行一轮，不连续补跑多轮。程序不会唤醒电脑，也不安装系统计划任务。

## 更新什么

自动任务通过本机已有登录会话在后台读取作品管理列表，更新已经核对入库且ID归属唯一的作品。播放、互动、完播等指标以本次平台真实返回的字段为准，保留原始历史观测。没有返回的字段不填零、不伪造新的观测时间。

新作品需要单独同步、核对归属；自动更新不会把新ID加入个人作品库。只导入CSV但尚未核对过采集归属的作品不直接进入自动更新范围。私密、下架、缺失或列表未读完时，可能只刷新部分已有作品；状态会说明，不声称全量数据均已刷新。

自动模式只读取创作者列表，不额外逐条打开公开详情或补下载封面。保留既有数量／转化双线、图文阅读深度及全部有效历史参照规则。采集间隔也不保证命中每个作品的精确固定窗口，复盘仍只使用真实符合窗口条件的观测。

## 什么时候暂停

正在手动同步时，自动任务不会争用浏览器。登录失效或出现验证码时暂停；请先手动同步并完成登录／验证，再回到自动更新设置点击保存恢复。平台异常或网络失败保留已有数据，按后续计划重试。

关闭开关并保存后不再启动新任务，正在进行的任务会完成本轮，也可在同步区点击停止。

设置与运行记录位于主数据库旁的 `.auto-update.json` 文件，不含密钥或登录凭据。更换数据库或迁移路径后重新启用；常规数据库备份不包含这份调度设置。

本轮以临时数据和模拟浏览器验证定时任务与自动入库，不代表已对个人账号完成长期在线运行验收。个人账号默认未启用，需要按上方步骤保存设置。
