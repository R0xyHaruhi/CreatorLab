# 2.6.1 修复说明

修复2.6覆盖安装不完整、顶部标题被工具栏遮挡，以及战力卡入口和综合位置展示被改变的问题。

- 战力挑战恢复为独立一级入口，默认首屏。保留六维图、综合位置、类型称号、原始指标、海报预览、昵称隐私和PNG保存。
- 提供“数量战力 / 互动效率”口径切换，默认数量；综合位置明确标注计算口径，非内容质量或全站评分。默认不限制作品年龄。
- 顶部工具栏退出固定覆盖布局，CLab改为完整一级标题；作品列表、作品选择标签及详情不再由代码截断标题。
- 修复覆盖包包含全部应用模块、精选模块、100期参照库、字体和依赖清单，不再要求先安装2.5。精选模块意外缺失时显示局部恢复提示，不中断战力卡和其他页面。

关闭CLab，将修复覆盖包内全部文件解压覆盖到包含app.py的原程序目录，然后用原脚本启动。无需删除local目录，也无需重新采集已有作品。覆盖包不包含个人数据和浏览器会话。完整包用于解压到新目录，需要自行复制旧local文件夹。

数量和比例仍分别展示，缺失不填0。综合位置是各共同维度排名等权平均后的当前样本位置，不是流量预测或质量评分。互动效率可能偏向小分母，需结合原始数量判断。
