# CLab 1.5.1 · 恢复明暗切换、可见图表与B站空间

这次修正1.5改版中功能入口被移除或隐藏过深的问题，保留引导式复盘。

## 三个入口

- **侧栏 → 明暗切换**：柔和深色 / 暖灰浅色，点击即切换，不用重启。图表背景、文字、网格与提示框使用同一配色；主要页面的表格改用可随主题换色的静态表格，避免保留深色画布。
- **数据分析 → 先看重点**：直接显示作品表现横条图。新增 **图表总览**，提供作品表现、播放分布、播放与观众反馈的散点图，不需要先分类。分类、时长与角色交叉图仍在“按内容找规律”，不会因简化文字被移除。
- **侧栏 → 平台空间 → B站空间**：独立筛选B站账号、作品库、分析与创作助手；提供已保存UID的B站主页链接和创作中心入口。这里不再展示抖音同步按钮。内容关联保留跨平台数据，方便关联抖音与B站版本。

## 数据不足时

未分类也显示实际作品图表，只暂停“哪类更好”的判断。目标指标缺失时明确提示，播放图会注明仅展示已知播放，不能当作目标指标结论。发布时间未知或范围内无成熟作品时，保留已知指标图并说明不能用于分类优劣判断。没有真实作品时不生成假图表。

B站自动后台同步仍未实现；支持保存账号、CSV、手动录入与已有数据分析。B站空间不是自动抓取能力的承诺。

## 更新步骤

关闭旧服务，备份并复制原 `local` 文件夹到新包目录，再运行 `start_windows.bat`。首次运行新版本需要重启；启动后明暗切换无需重启。不要删除原数据库。

如果浏览器的Streamlit原生设置有固定主题，本版本应用内明暗切换仍会覆盖主要页面组件与图表配色。旧版工具页面独立保留，不属于本轮主要页面适配范围。

## 验证范围

验证了应用内双向切换、两种主题的图表配色、未分类图表、B站与抖音空间隔离、缺少成熟记录时保留实际图表。尚未在你的Windows浏览器进行截图验收。
