# CreatorLab 2.6.18：一次只做一件事

保留“创作者剪辑台”的字标、平台背景、数量实线与转化虚线，将八个顶层标签改为四个任务入口。默认页面只加载当前任务，不再同时呈现所有分析和工具。

| 入口 | 先做什么 | 需要时再打开 |
| --- | --- | --- |
| 看作品 | 选一条作品，看战力图、直观结论和下一步 | 页面下方“更多分析方式”：详细数据、作品对比、外部作品、账号总览；侧栏可调整参照口径 |
| 做下一条 | 准备创作、检查视频、记录与复盘，三选一 | 参照证据、模型、历史方案、发布规律与深入分析 |
| 作品库 | 搜索作品，打开对应报告 | 筛选与排序、对比、导出和编辑 |
| 同步与设置 | 同步作品并查看任务进度 | 账号与文件导入、备份与诊断、使用帮助 |

推荐路径：在“看作品”选中作品，点击“为下一条做个计划”，作品会自动带入。只选择一个改动方向，点击“保存并开始验证”，直接进入对应实验。下一条发布后关联作品，等待真实窗口数据，再记录经验。

战力图、PNG导出、数量／转化双线、图文阅读深度、平台隔离与筛选均保留。默认历史参照和指标计算不变；本轮不改变采集与数据库逻辑，不覆盖 `local/` 的个人数据。

阶段4—6详细使用与边界见[创作闭环指南](../../CREATIVE_WORKFLOW.md)，本地检测和可选AI见[视频体检指南](../../VIDEO_INSPECTION.md)。付费模型和完整在线采集没有在本轮重新实测。
