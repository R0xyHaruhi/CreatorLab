# CLab 1.9.1 · B站采集与空画像修复

本版针对“B站只有播放量、发布时间未知、封面损坏、画像为空”和“按赛道词搜索同名用户”修复。1.9 的采集链路存在实际错误，不能仅用界面和本地测试数量证明已经可用。

## 本次修复

- 修复空间卡片回退路径引用未定义 `fresh` 变量导致的中断。接口响应、页面卡片和视频详情使用同一个保存入口，仅给本次真实取得的字段记录新时间。
- 支持空间 `/UID/video` 与 `/UID/upload/video` 两种路径。视频详情增加嵌套页面状态、HTML中的JSON数据及可见精确数值回退；视频ID和作者UID必须同时匹配，不将推荐视频指标串入本人的作品。
- 等待详情加载并重试；识别验证码/登录标题时留在当前窗口等待用户处理。发布时间、原封面地址及互动字段的缺项进入定向补采。仅识别到作品列表，不再报告指标完整。
- 视频页内嵌的账号粉丝等信息也可参与补采。能取得时保存平台分区、标签和简介；精确匹配的分区或明确标签产生可修正的赛道建议，保留用户手动分类。
- 画像至少有3个可评分维度才绘制；否则显示缺项原因和“一键补齐B站数据并重建画像”入口。缺失值不补零。封面只展示真实本地缓存，避免第三方地址防盗链造成破图。
- B站学习对象入口改为视频搜索，从视频作者中提取候选，并展示匹配作品作为依据。搜索词可结合已采到的标签或用户主题；不再把用户名包含“日常Vlog”视为赛道匹配。赛道无法识别时保持未确认。

## 升级和补采

1. 关闭旧程序，备份旧 `local` 文件夹。将其副本放入新包目录，再双击 `start_windows.bat`。
2. 打开“数据分析 → 成长面板 → 作品画像”，点击“一键补齐B站数据并重建画像”；也可以在侧栏选“补齐缺失 / 到期窗口”。
3. 保持采集窗口打开，出现登录或验证码时在该窗口完成。结束后点击“刷新画像数据”。已入库作品按BV号补齐，不必删除重建。
4. 检查实际字段完整度，而不是只看已识别作品数。至少3条同组作品可开启小样本探索，常规画像每轴要求5条；观察时间与比例口径仍遵循1.9说明。

## 验证结果与限制

- 94项本地自动检查通过，包含新增的无接口卡片导入→详情JSON补齐→本地缓存→账号粉丝读取的模拟浏览器流程，以及空图隐藏、完整六轴多边形、作者身份绑定、搜索作品证据和手动分类保护。
- 实际访问截图中的 UID `62473140` 时，当前执行环境收到的是B站验证码页。没有取得该账号完整作品指标，因此本版不是“该账号已线上采集成功”的交付声明。
- 此环境的本地浏览器下载失败，未完成真实浏览器端到端验收。模拟浏览器与页面解析测试不能代替真实账号验证。
- 仍受B站页面结构、登录状态和验证影响。没有绕过验证码、后台自动登录或保证所有字段必定可见。仅有“1.2万”这样的缩略显示时，不当作精确值写入统计。
- 公开搜索匹配说明候选的某些作品与关键词相关，不能据此宣布其为赛道头部或确认整个账号垂直度。
