# CLab 2.6 更新：第1—3步

1. 关闭正在运行的CLab，并备份原程序目录。
2. 现有2.5用户将升级补丁覆盖到包含app.py的原目录。补丁没有local目录，不覆盖个人作品或浏览器会话。
3. 使用原start_windows.bat或start_mac_linux.sh启动。
4. 从“总览”进入账号作品库；点作品“查看报告”。勾选2—3条作品后点击“对比所选作品”，默认显示Overall。
5. 任务进度、停止与补采在“采集任务”。抖音采集仍须核对账号归属再入库。

完整包请解压至新目录，再将旧版local文件夹复制至新版同名位置，保留旧目录作为恢复副本。本轮依赖及个人数据库schema不变，继续使用64位Python 3.12。

封面请求不再逐张新开页面；个人画像以实际数量为主，不强制按作品年龄分组，不再合成综合质量百分比。B站精选100期参照保留。

详见docs/STUDIO_GUIDE.md。真实Windows在线采集与桌面视觉仍需本机验收。
