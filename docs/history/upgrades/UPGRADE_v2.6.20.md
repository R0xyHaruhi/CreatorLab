# CreatorLab 2.6.20：读到了，不再看起来像闪退

2.6.19的首页同步读取完就关闭源窗口。如果响应不含可核实的作者标识，新作品会停在待确认区，用户容易将这个流程误认为闪退和漏采。

现在需要归属确认时，采集窗口会保留最多10分钟。返回CLab，「待核对的抖音采集」紧跟同步区显示，新作品优先展示，并明确说明尚未入库。核对账号和作品后勾选确认，点击「确认归属并入库」，源窗口随后结束，作品进入作品库。窗口开着时也能执行确认。

已有可靠作者绑定且逐条通过原核对规则的作品仍可自动入库，成功后源窗口停留5秒再结束。没有作者标识的新ID不绕过人工确认。

如果手动关闭窗口、点击停止或等待超时，已经读到的作品保留在待确认区，**无需重新同步**。上次已保存的待确认批次同样可以直接核对入库。

本轮未自动确认个人作品归属，也没有重新使用真实账号在线采集。窗口等待、确认入库、手动关闭及超时使用临时数据库和模拟浏览器测试；实际界面使用个人库的隔离副本检查。
