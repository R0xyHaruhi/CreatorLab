# CLab 2.2 · 工作台界面调整

本版聚焦视觉层级与日常操作，保留战力卡、数据分析、抖音/B站独立空间与原有采集逻辑。

- 主导航改为“画像、作品、对比、分析、设置”，删除主界面的emoji和口号式标题。
- 首页以可交互六边形图为中心，悬停可查看原始值、历史位置与参照样本数。右侧紧凑排列六项指标与一条复盘建议。
- 长海报不再挤占日常工作区。保存战力卡直接可见，昵称开关与海报预览放入“分享选项”，默认关闭预览与昵称。
- 使用石墨灰/暖灰底色和少量蓝色强调，区分主按钮与次级按钮；统一小圆角、细分隔线、等宽数字间距和更紧凑的导航。
- 数据未齐时继续显示真实数值、缺项和补采入口；不为了好看生成空战力图或假数据。
- 隐藏框架自动生成的“app/旧版工具”导航和部署按钮。团队旧版仍可从侧栏“团队与旧版”进入。

## 使用

关闭旧程序与采集窗口，备份 `local` 文件夹，将副本放入新包目录，启动后默认进入“画像”。抖音和B站分别选择空间。完整分析位于“分析 → 分析与实验”，跨平台关联仍是单独入口。

这是现有Streamlit应用内的界面重整，没有更换前端框架。本轮用本地应用检查验证交互图表、图片导出、平台切换和原有流程；没有完成真实浏览器对全部窗口尺寸的视觉验收，也没有新增真实登录采集验收。原有采集边界继续适用。
