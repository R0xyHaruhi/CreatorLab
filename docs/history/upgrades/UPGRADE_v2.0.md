# CLab 2.0 · 看见创作力

个人空间改为以可视化为中心：先看到作品的形状，再决定要比较、分享还是尝试一个改动。

## 五个入口

| 入口 | 用途 |
| --- | --- |
| 我的战力卡 | 选择作品，生成六维卡片，显示特色称号与一条实验建议，保存分享图片 |
| 我的作品 | 浏览和搜索作品；筛选与排序默认收起 |
| 作品对比 | 叠加两条作品的六维形状，再选一个指标看条形对比 |
| 创作进阶 | 保留交叉分析、赛道分类、学习对象、实验、素材复盘和跨平台关联 |
| 设置 | 账号、手动/CSV导入、账号统计、说明与验收 |

## 分享卡

- 输出1080×1320 PNG，深浅配色跟随明暗切换；中文字体随包附带，不需要额外配置截图工具。
- 分享图包括作品标题、六维形状、特色称号、部分原始指标和比较口径。默认不展示昵称，可自行开启。
- 称号是视觉表达，不是平台认证、全站排名或综合能力评分。数字仍是当前作品在自己同账号、同平台、相近作品年龄组中的历史位置。
- 每轴至少3条记录开始探索；有效轴样本少于5条时注明小样本。至少3轴可评分才解锁分享卡。缺失轴显示待解锁，不补零；没有完整六轴时不填满多边形。
- 首屏自动优先选择已具备可比数据的作品。数据未齐时显示解锁进度与补采入口，不生成假战力图。
- 战力卡上的“一招”可加入创作实验。随后到“创作进阶 → 数据与实验”关联新旧作品；建议是待验证的做法，不保证增长。

## 保留的功能和边界

明暗切换、B站空间、抖音同步、手动数据、统一分类、固定时间窗口、可冻结参照的详细画像及原有图表均保留，放在对应的次级入口。首页分享卡默认使用当前累计与当前历史组；需要固定参照或24小时/7天/30天观察时进入创作进阶。

本版主要重做个人区的呈现与分享体验，没有将B站采集宣称为已完成真实账号验收。此前实际访问 UID 62473140 时遇到验证码页，相关限制仍以1.9.1说明为准。

## 升级

关闭旧程序，备份 `local` 文件夹，将其副本放入新目录，再双击 `start_windows.bat`。原有作品和分类保留。

字体来自Noto CJK，按SIL Open Font License 1.1分发；原字体与许可位于 `assets/fonts/`。
