# 2.6.7 累积小补丁：私密作品直接提示无法获取

适用于已安装2.6.5或2.6.6。包含2.6.6占位标题状态关联修复，无需先单独安装2.6.6。

按本轮用户要求：已确认私密的作品单独显示数量，并提示“当前无法获取数据；如需采集，请在抖音改为公开，再回到CLab重新同步”。不计入数据异常或待补采，不继续补私密作品的互动与封面。原有采集逻辑已跳过已确认私密作品，本轮保留该行为。

总览、采集任务、侧栏和作品报告使用同一提示。私密报告中的已有数值标为历史记录，不代表当前可获取数据，且不显示公开表现评分。

不根据0播放猜测私密。未知状态仍可核实；已确认删除等其他不可公开状态不会被混称为私密。未在平台自动修改作品权限。

安装：关闭CLab，按原路径覆盖本包到app.py所在目录并重启。不是完整独立安装包，不删除个人local目录。覆盖后显示方式需实机复验；已知89条平台总数与可见列表差额仍保留，不能推定为私密或已采齐。

验证：相关29项回归通过；15条环境包元数据弃用警告。另用私密作品数据验证总览和报告可渲染并给出数量与公开后重采提示。
