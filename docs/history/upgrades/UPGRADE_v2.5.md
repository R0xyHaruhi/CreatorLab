CLab 2.5 每周必看100期接入补丁

适用于现有CLab 2.4。
1. 关闭CLab，备份原程序目录。
2. 将本补丁所有文件解压覆盖到含app.py和creatorlab文件夹的原目录。
3. 使用原启动脚本重新启动。

入口：B站空间 → 战力挑战 → 精选样本；或作品对比 → 每周必看 · 精选样本。
内置第292—391期，4,600条有效作品，4,539条有标签。公开精选样本不是全站统计；默认不按发布时间限制。
参照库与个人作品数据库独立；补丁不包含local目录，不覆盖个人数据。
原来的个人作品战力计算保持原有逻辑。本入口分开显示数量、比例，不合成质量总分。
详细说明见docs/WEEKLY_REFERENCE.md。
