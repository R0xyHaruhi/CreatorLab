# CLab 2.3 · 有内容层次的可视化概览

上一版只在数据齐全后展示画像，数据不完整时首页被缺项占据。本版增加可直接利用现有数据的概览。

## 首页结构

1. 账号概况：已入库作品数、已知累计播放、中位数、最高单条播放。
2. 核心图：数据足够时展示六维画像；数据不足时展示真实播放分布，并高亮当前作品所在区间。
3. 当前作品：标题、播放值、当前累计排序，以及紧凑的补采入口。
4. 作品排行：前六条作品的播放条形图，可点击条形切换上方作品。
5. 分类表现：存在至少两个内容分组时，对比中位数并显示样本；优先选同账号、同发布时长范围。否则展示原始字段覆盖地图，让缺项的分布可见。

六边形图和分享导出仍保留；没有足够真实参照时不生成分数。抖音、B站继续独立展示。

## 数据解释

- 播放分布、累计排序、累计总和使用当前已保存的可信正播放记录，不表示同龄作品能力、周新增播放或内容效果。
- 顶部会标记多少作品有可展示的播放数据。零播放待核实、私密或明显异常作品不会被混入正播放排行。
- 分类积累时间无法对齐时，明确标记“仅看分布”；不把分组差异解释成因果。样本数在图表悬停时显示。
- 覆盖地图的亮色仅表示原始字段存在，包括真实的0；不表示该字段质量高。深色表示缺失。
- 本地检查覆盖模拟的203条仅播放记录：必须展示真实分布、排行和覆盖地图，且不出现虚假雷达图。该模拟不等于已读取用户电脑上的203条实际作品。

## 升级

关闭旧程序，备份并迁移 `local` 文件夹，从新目录启动，进入“概览”。本次未修改平台采集能力，也未完成真实浏览器视觉验收；原有采集限制仍适用。
