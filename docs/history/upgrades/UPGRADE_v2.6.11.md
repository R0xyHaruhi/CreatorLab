# 2.6.11 累积更新：图文专用六维战力

适用于2.6.5—2.6.10。关闭CLab，将压缩包内容按原路径覆盖到app.py所在目录，重新启动并刷新页面。无需逐版安装，不覆盖local个人数据。

## 新计算方法

前五轴为播放、点赞、评论、收藏、分享；保持数量与互动转化双线。图文第六轴改为阅读深度：数量线比较平均浏览图片数，转化线比较平均浏览图片数÷作品总张数。两条线都是各自原始数值在其他有效图文中的历史位置，至少3条其他有效参照才评分，不是平台官方评分或内容质量总分。

图文转化轴（含阅读深度指数）保留播放至少1000的样本稳定性门槛。小播放作品仍显示真实原始值，不因极小分母获得高转化评分。

默认全部作品保持前五轴参照同账号、同平台的全部公开有效作品。图文阅读轴只参照图文；视频完播轴只参照有有效观测的视频。视频与图文混合的综合排名只使用前五个共同维度。新增“全部类型 / 仅视频 / 仅图文”选择；纯图文范围数据足够时加入第六轴。仍保留全部作品 / 同赛道的分类选择，不强制作品年龄分组。

阅读深度指数100%表示平台提供的平均浏览张数等于总张数，不能解释成100%的观众看完。源数据可能取整；平均浏览张数大于总张数、缺少总张数或非同期观测时，不生成深度指数，也不截成100%。固定观察窗口目前没有图文浏览窗口观测，不能拿当前累计指标回填。

## 采集与呈现

- 从后台当前作品卡读取图片张数、平均浏览图片数、划走率、文案展开率。继续修复置顶标签和无张数标签的图文识别，不猜测总张数。
- 数据通过既有采集归属核对流程入库，独立记录图文指标及观测时间；保留原数据库历史记录，不把图文指标伪装成视频完播率。
- 页面显示真实图片总数、平均浏览张数、深度指数；划走率和文案展开率仅作辅助说明，不加入综合分。
- 保留六轴图、数量/转化双线、战力卡PNG导出；PNG增加图文阅读原值与指标解释。
- Overall与作品报告补充图文指标，并保留小数张数，1.8张不会被格式化成2张。

本次真实后台只读核对13条图文：13条有平均浏览图片数，12条有总张数；“尼古喵喵”3张、平均3张，深度指数约100%。另一条“难道他真的是鲁迪乌斯？”没有总张数标签，平均1.8张，不能从1.8推算总张数，保留缺项。

## 安装后的必要步骤

本版本新增图文指标，旧数据库没有这些观测。覆盖重启后，再执行一次“抖音同步”，才能保存真实指标并启用图文阅读轴；只重启不会自动凭空补齐数据。缺项时仍显示现有五维，不补零、不制造完整六边形。

验证：244项完整自动回归通过；最后调整平均浏览张数的小数显示后，相关回归再次通过。覆盖采集DOM解析→唯一作品匹配→采集暂存→核对入库→图文观测读取→深度计算、混合五轴/纯图文六轴排名、页面切换和PNG导出。docs/previews/image_reading.png为明确标注DEMO的演示，已检查导出排版。尚未覆盖到用户Windows目录，安装后真实入库和显示仍待验证。
