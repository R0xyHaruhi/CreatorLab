# CLab 1.7 · B站账号、作品与创作中心数据

## 本轮修复

1.6只存作品，未建立账号指标快照；视频字段也漏了投币和弹幕。本轮补齐存储、采集适配与展示，并把三种数据范围分开。

| 层级 | 采集适配字段 | 工作台入口 |
| --- | --- | --- |
| 账号公开统计 | 粉丝量、关注数、累计获赞、视频累计播放、专栏累计阅读、公开投稿数、专栏数 | 首页 → B站账号数据 |
| 单条作品 | 播放、评论、弹幕、点赞、投币、收藏、分享 | 作品详情、反馈图表 |
| 创作中心视频概览 | 播放、评论、弹幕、点赞、投币、收藏、分享，以及页面统计截止日 | 首页 → 创作中心·视频汇总 |

“支持字段”表示已有对应采集与存储适配，不保证本次页面一定返回。缺失字段显示未采集/未知，不写成0。真实0值会保留。

## 如何更新和采集

1. 关闭旧服务，备份旧 `local`，复制到新包后运行 `start_windows.bat`。启动会自动给原有作品快照增加投币、弹幕列，保留原数据。
2. 进入「B站空间」，在侧栏填写自己的UID。
3. **作品指标补全范围**默认选择“全部已导入作品（较慢）”；也可选“最近50条”或“仅列表（快速）”。逐条访问作品页补全指标，范围仍受单次5000条上限限制，可停止后重试。
4. 若需要截图中的创作中心数据，勾选 **采集本人创作中心概览（需登录）**。采完列表后会打开创作中心，请在窗口中登录对应UID，并打开 **数据中心 → 视频数据**。该阶段最长等待3分钟，之后继续补充作品指标。
5. 点击刷新作品库查看数据和完整度。已有作品不会重复建条目，分类标签保留。

## 粉丝数据

采集正常空间页面返回的关系统计、账号卡片等响应，也尝试读取空间页上明确、完整的粉丝数字。只有“1.2万”等缩写、没有完整数值时不推算。首页会显示粉丝量，并保存观测记录；至少两条粉丝观测记录时显示趋势。

趋势只表示实际观测点之间的差异，不凭当前粉丝量补造历史，不将净变化当作新增关注和取关的分别统计。每个字段均保留来源与采集时间，可展开查看。

## 作品数据

- 投币和弹幕有独立数据库列，不再丢弃，也不与评论混用。
- 作品详情可查看这些指标；分析新增投币/播放、弹幕/播放参考比例。
- 逐作品统计既尝试监听页面响应，也尝试读取该作品页面已加载的数据；检查BV号和UP主UID。
- 导入面板显示7种作品指标分别有多少条，访问过页面不等于指标已补全。
- “投稿列表已导入”只表示记录数量达到列表报告总数，不表示所有字段已齐全。

## 创作中心概览

必须观察到本人登录身份，且UID与目标一致，才保存后台概览；无法验证或登录错号时不入库。读取带“视频数据”和“统计截至”日期的可见页面短标签块，至少有3个明确的整数指标才保存；缺失的项继续留空。

后台概览与作品快照、账号公开统计分别存储，不用作品加总冒充后台汇总。保留平台页面统计截至日期，并注明“未自动确认统计起始日”，不擅自标成近7天、近30天或生命周期总数。

目前是适配截图所示的视频概览，**不代表已接通全部创作中心报表**。粉丝画像、关注来源、取关明细、流量来源、收入、分时留存等未在本轮完成。

## 测试与边界

覆盖账号归属、粉丝0值、公开与后台范围隔离、旧数据库迁移、投币弹幕映射、页面展示、分页、去重、按钮和主题。用模拟DOM检查概览标签读取与完整粉丝数字读取。

尚未在你的真实登录B站页面完成在线验收。空间请求结构、界面标签或登录校验流程变化，可能导致部分字段无法取得；此时以面板“未取得/完整度”提示为准。没有把测试构造数据当作真实采集成功。
