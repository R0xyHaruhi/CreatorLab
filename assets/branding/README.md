# 平台标识

图形来源为 [Simple Icons](https://github.com/simple-icons/simple-icons)，原图保存在本目录。`bilibili.svg` 为B站小电视标识，`tiktok.svg` 为抖音／TikTok共用的音符形状，用于页面的平台识别。

上游图形以 CC0 1.0 提供，原许可证见 `LICENSE-simple-icons.md`。平台商标权归各自权利人。应用本地加载图形，运行时不请求外部图标服务。

当前B站背景改用 `bilibili-mascot.svg`：带表情的小电视，来自 [Arcticons](https://github.com/Arcticons-Team/Arcticons)，作者 Donnnno／Arcticons contributors，通过 [Iconify公开集合](https://github.com/iconify/icon-sets/blob/master/json/arcticons.json) 提取。此文件按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 保留，矢量图形未修改；应用仅在显示时设置颜色和透明度。旧的Simple Icons圆眼版本保留作来源记录，不再用于页面显示。
